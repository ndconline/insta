Broaden discovery

Works for any BLE device, not only the mic. Check any group below before connecting to request access to those services too. A device that shows almost nothing after Discover, one service and no writable characteristics, usually has a vendor-specific control service that was never requested. These checkboxes cover the service UUIDs most devices reuse from reference chip designs, so this often finds it without needing the exact UUID.
For the complete picture with no restriction at all, Chrome and Edge ship a built in inspector: open a new tab, go to chrome://bluetooth-internals, and use its own Scan and Inspect buttons. It shows every service and characteristic a device exposes, including ones this page is not allowed to see, which is the fastest way to find an unknown vendor UUID. Paste anything useful you find back into the field above.

Services and characteristics

Connect to a device on the Connect tab, then click Discover.

Send raw bytes

Options tagged "GATT internal" belong to the Bluetooth stack itself (feature negotiation, caching), not to the device, they will not do anything useful and are only listed because the spec marks them writable. If a write fails with "GATT Error Unknown," that specific message is a known Chrome quirk, most common on Windows, and does not always mean the command itself was wrong, see the Log tab for suggestions logged alongside the error.

Insta360 Mic Pro settings (experimental)

These map to the settings shown in the official app. Insta360 has not published the command bytes, so each hex value below starts blank. Fill one in once you have decoded it (see docs/REVERSE_ENGINEERING.md), pick the characteristic it belongs to, then use the buttons to test it live. Values you fill in stay in this tab only, nothing is saved to disk.
